# BrowserAddonsView - Extensions Installed on This PC

At a glance:
- Add-on names for browsers on this machine
- A read of what this user installed
- Removal done in the browser, for an add-on you know
- No cookies, no passwords, and no other account

## The Names

BrowserAddonsView shows extensions the browsers on this PC have recorded. The useful question is whether you installed that name. If you do not recognize it, do not click through a random removal guide. Open the browser you use, look at its own extension page, and disable one add-on you are sure you do not want. Restart the browser and see whether the site you need still works.

A list that includes another browser you never open is still this PC. Do not export the list to a forum with your account details in the paths. The tool reads local installation data. It does not log into the browser as you, and it should not be asked to dump sessions.

## Disable What You Know

Remove or disable from the browser's own page so the browser can turn the add-on off cleanly. Deleting a folder because the viewer showed a path can break the profile. If an add-on is required for a work site, leave it until you have another way to sign in. One change, then a test, then the next name.

Do not install a "replacement" extension from an ad because this list looked short. Add-ons are code that can read pages you open. Fewer is fine.

## Not A Session Copier

Cookies, saved passwords, and open tabs are not the job. If a tool offers those, it is a different program, and taking them from a browser you do not own is not allowed. This viewer is a name list. Close it when you have seen the names. Sign out of the browser on a shared PC so the next person does not inherit the profile.

## One Browser At A Time

Filter your attention to the browser you actually use. A name in an old profile may be leftover. Confirm in that browser before you delete files. If two Windows users share the machine, each has their own add-ons. Read yours.

## After A Change

Open the site you need and sign in the ordinary way. If it fails, re-enable the add-on you just removed. Do not remove three more while the first site is broken. The viewer can be opened again later to see whether the name is still listed. It does not have to stay running.

## Leave The Name You Cannot Place

An add-on you do not recognize stays until you can read its entry in the browser itself. Removing three unknown names in one sitting is how a work site breaks. One name, one test, then stop.

## Help Desk

A site broke? Re-enable the last add-on you disabled. Do not remove more.
You do not recognize a name? Leave it until you can read what it is in the browser's own page.
The list is empty? That browser may have no add-ons, or you are looking at the wrong profile.
You wanted saved passwords? Stop. That is not this tool.
You are in another person's account? Close the window.

## Reader Notes

Read names, change one, test. The viewer is the index. The browser is where the change happens. Deleting a folder from the path column is how a profile breaks.

Do not treat an unfamiliar add-on as something to replace from a search ad. If you did not install it and you share the PC, ask the other user before you disable their tool.

Export is rarely useful and often too revealing. Skip it. Close the program when the one name you cared about is confirmed.
